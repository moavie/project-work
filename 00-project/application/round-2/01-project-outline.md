# League of Legends Match Data Warehouse

This project focuses on building a data warehouse for League of Legends match data using the Riot Games API. It collects raw match data, processes it through an ETL pipeline, and stores it in a relational database for analysis. The goal is to make it easier to analyze champion and player performance using SQL queries.

## Objectives

- Fetch real match data from the Riot Games API.
- Store raw data and transform it into structured database tables.
- Build a data warehouse for match statistics.
- Write SQL queries to analyze game and champion performance.

## Scope

**In scope:**
- Working with the Riot Games API.
- Designing the staging layer and data warehouse schema.
- Implementing the ETL pipeline.
- Writing and testing analytical SQL queries.

**Out of scope:**
- Real-time match analysis.
- Collect all datas from League of Legends matches without any defined scopes.

## Notes

The project will start with a small set of match data to test the database design and ETL pipeline. After the basic process works correctly, the dataset can be expanded and query performance can be improved.
